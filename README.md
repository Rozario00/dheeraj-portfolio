# Dheeraj C Portfolio - Graphic Designer & AI Creative

Project name: `DHEERAJ-PORTFOLIO`

A static portfolio for Dheeraj C, a fresher building a graphic design practice through personal and AI-assisted creative concepts.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts and Font Awesome CDN

## Folder structure

```text
index.html
style.css
script.js
assets/
  images/
```

Project previews are currently CSS-generated so the site has no stock-image or copyright dependency. Real assets can be added later in `assets/images/` and connected from the project visual blocks.

## Run locally

Open `index.html` with VS Code Live Server, or serve the folder with any simple static HTTP server. No build step or package installation is required.

## Deploy to Vercel

Import the repository into Vercel and choose the project root as the deployment directory. Vercel will serve `index.html` as a static site with no build command.
